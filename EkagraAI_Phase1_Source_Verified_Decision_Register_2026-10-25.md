## 2. Present architecture — preserve

1. **Frozen study version and reconstructable output records.** `studies/loader.py:24–46`, `studies/compiler.py:29–55`, `studies/canonicalization.py:19–26`, `studies/activation.py:9–25`, `studies/catalog.py:9–20`; `db/models.py:15–35,130–158`. Source YAML is parsed, validated, compiled, canonicalized and stored with hashes; session references its study version. Raw provider text, response payload, parsed response, prompt/request payload, tokens, latency, errors and retries are stored.
2. **Separation of scientific responsibilities.** `runtime/ai.py:307–312,429–444`; `runtime/engine.py:35–70,133–164`. Judge produces correctness/structural/evidence observations; the deterministic rubric makes the pass decision. `MATERIALLY_INCORRECT` remains a blocking correctness gate, even when target-level structure appears to be present. Preserve this independence—**do not create a blanket rule forcing correctness from SOLO evidence**.
3. **Independent assessment selection and blindness.** `runtime/engine.py:112–124`; `runtime/ai.py:299–312`. Selection uses unseen form IDs rather than pedagogy identity. Judge's request supplies frozen learner task, hidden scoring context and scoped rubric/evidence material, not pedagogy ID, previous results or Tutor transcript.
4. **Pilot attempt logic and non-fabrication of formal state.** `runtime/engine.py:100–110,133–197`. One unused pedagogy per attempt up to the pilot cap, outcome `UNRESOLVED` on exhaustion, and formal SOLO state advances only on a qualified deterministic pass. **Administrative section navigation is not proof of SOLO progression**.
5. **Existing provider auditing, response schemas, error recording and idempotency.** `runtime/ai.py:55–105,158–234,319–345,380–447`; `web.py:255–296`, with raw error histories preserved. Maintain technical retry separate from a *new scientific intervention attempt*.
6. **Current participant-safe projection rather than exposing hidden scoring fields.** `web.py:202–225`, `templates/partials/session_main.html:48–49`; preserve strict separation while redesigning assessment later.

### Additional research-design boundary (outside the present pilot implementation)

The professor's **Experiment 1** direction is three persistent matched topics within one domain, randomized starting pedagogy assignment across topics at each SOLO transition, independent without-replacement fallback within each topic, repeat randomized cycles until success or an approved cap, and post-hoc reward analysis. This differs from the current **single-topic, max-three-attempt Fibonacci pilot**. Do not call the current implementation an implementation of that revised research protocol. Neither the pilot reliability fixes nor Phase 2 MCQ schema should silently implement the professor's topic/cycle pivot or pre-study baseline decisions.

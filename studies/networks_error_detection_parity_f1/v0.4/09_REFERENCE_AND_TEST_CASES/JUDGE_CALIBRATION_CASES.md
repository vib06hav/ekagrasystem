# Synthetic Judge calibration hypotheses — 20 cases

The accompanying JSONL lists author-proposed examples of valid alternatives, false mechanisms, partial/strong structural responses and review ambiguity. These are **not expert-rated ground truth**, and intentionally have no fixed mandatory learner question. A test must attach a compatible exact generated task; otherwise the same learner response may warrant a different score. Human raters must adjudicate item-specific examples before any Judge reliability claim.

For every C1–C4 transition, collect real learner-style responses with variable prose, alternative explanations and invalid computations, send through **live blind Judge**, compare explanations to actual verified scenario. No regex, expected string or stub-generated score counts as semantic validation.
